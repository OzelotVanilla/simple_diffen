Simple Diffen is a diff/compare tool that uses JavaScript (jsdiff is used) to show diff information.

It runs completely on local browser environment (offline, no data uploaded to server for comparison), and could be downloaded as a single HTML file even the online version does not work.

If you downloaded this page, do not forget to check if there is an update sometimes !
